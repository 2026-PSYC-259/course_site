Schedule

Week 01, 09/28: Course Goals and Setup

Read before class: R4DS Introduction

  • Goals of the class
  • Logistics
  • Workflow examples
  • Software setup
  • Introduction to Github
  • Instructions to set up R, RStudio, git, and Github

Week 02, 10/05: File Organization and Workflow

Read before class: R4DS Workflow Basics, Scripts and projects, and Data import

  • File organization
  • Version control
  • SKILLS: R language basics (variables, assignment, comments, calling functions), file import/export

Week 03, 10/12: Data Transformations

Read before class: R4DS Data transformation, Numbers, and Strings

  • Basic data types (numbers, strings)
  • Variable naming
  • SKILLS: dplyr data wrangling, logical statements, strings

Week 04, 10/19: Data Structure

Read before class: R4DS Tidy data, Factors, and Dates

  • Tidy data (observations/cases)
  • More advanced data types (factors, dates, vectors, lists)
  • SKILLS: More data wrangling, factors, dates

Week 05, 10/26: Workflow Critique Presentations

Week 06, 11/02: Automation: Functions and Iteration

Read before class: R4DS Functions, Vectors and Iteration

  • Finding new packages/APIs vs. writing your own functions
  • Automating your analyses
  • Writing more efficient code
  • SKILLS: Writing custom functions, iteration (map, for loops)

Week 07, 11/09: Exploratory Data Analysis

Read before class: R4DS Data visualization, Layers and Exporatory data analysis

  • Data validation
  • Automating visualizations
  • SKILLS: Basic visualizations with ggplot2

Week 08, 11/16: Data Sharing and Reproducibility

Read before class: R4DS Quarto and Quarto formats

  • Reuse-minded project management
  • Reproducible reports (Quarto vs. RMarkdown)
  • Preserving programming environment and analyses
  • SKILLS: R Markdown, package control

Week 09, 11/23: Visualization

Read before class: Chartjunk from (Tufte 1990; 2001; 2006) and R4DS Graphics for communication

  • Communicating through graphical styles
  • Interactive plots for data exploration
  • SKILLS: ggplot and extensions

Week 10, 11/30: Final Project Presentations
